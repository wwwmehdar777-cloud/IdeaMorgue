# مشرحة الأفكار — مشروع Android

## ما الذي يتضمنه هذا الإصدار؟
- مشروع Android Native باستخدام Kotlin و Jetpack Compose.
- واجهة عربية داكنة مع تنقل سفلي.
- شاشة رئيسية وحالات سريرية تعليمية تجريبية.
- أسئلة اختيار من متعدد وكشف تفسير الحالة.
- حفظ الحالات محلياً ومكتبة شخصية.
- اختيار مجال الاهتمام.
- واجهة أولية للمساعد الذكي مع توضيح نقطة الربط الآمنة بالخادم.

## تشغيل المشروع
1. ثبّت Android Studio حديثاً مع Android SDK 35 و JDK 17.
2. افتح مجلد المشروع `IdeaMorgue_Android`.
3. انتظر Gradle Sync.
4. شغّل التطبيق على محاكي أو جهاز Android (API 26 أو أحدث).

## ملاحظات مهمة
- هذه قاعدة تنفيذ أولية قابلة للتشغيل والتطوير، وليست إصداراً إنتاجياً مكتملاً.
- شاشة المساعد حالياً واجهة جاهزة للربط وليست متصلة بنموذج ذكاء اصطناعي.
- الحالات الموجودة أمثلة تعليمية توضيحية، وليست مكتبة طبية معتمدة.
- لا تستخدمها لاتخاذ قرارات علاجية مباشرة.
- يلزم بناء خادم آمن، ومراجعة المصادر، وإضافة المصادقة والمزامنة والإشعارات والاختبارات قبل النشر.
- لا تضع مفاتيح API داخل كود Android.

## بناء APK من الهاتف عبر GitHub (دون كمبيوتر)
1. أنشئ مستودعاً جديداً في GitHub، واجعله **Public** أو **Private** كما تفضّل.
2. ارفع جميع محتويات هذا المجلد إلى المستودع، مع المجلد المخفي `.github` وملف `.github/workflows/build-apk.yml`.
3. بعد الرفع افتح تبويب **Actions** في المستودع.
4. اختر **Build Android APK** ثم اضغط **Run workflow** إذا لم يبدأ البناء تلقائياً بعد رفع الملفات.
5. انتظر حتى تظهر علامة النجاح الخضراء، ثم افتح تشغيل العملية (workflow run).
6. في أسفل صفحة التشغيل ستجد **Artifacts**؛ اضغط `IdeaMorgue-debug-apk` لتنزيل ملف ZIP.
7. فك ضغط الملف على هاتفك، ثم افتح `app-debug.apk` وثبّته. قد يطلب Android السماح بالتثبيت من هذا المصدر.

إذا فشل البناء، افتح سجل العملية وانسخ رسالة الخطأ الحمراء وأرسلها لي لنصلحها.

**تنبيه:** نجاح بناء APK لا يعني أن التطبيق أصبح منتجاً مكتملاً. هذا إصدار تجريبي أولي؛ المساعد الذكي غير موصول بخدمة AI حتى الآن، والمحتوى السريري تجريبي ويحتاج مراجعة وتوثيقاً قبل الاعتماد عليه.
